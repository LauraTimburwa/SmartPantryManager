# 🥫 Smart Pantry Manager

A simple Android application developed to help users manage their pantry ingredients, keep track of available food items and discover recipes based on what they have at home. The app aims to make meal planning easier and help reduce food waste.

### 🛠️ Technologies
- Java
- XML
- SQLite
- Android Studio
- Git & GitHub

### ✨ Features
- Add ingredients to the pantry.
- View saved pantry ingredients.
- Edit and delete pantry items.
- Store ingredient information using SQLite.
- View suggested recipes based on available ingredients.
- View individual recipe details.
- Manage application settings.
- Save data locally so pantry items remain available when the app is reopened.

### 🧩 The Process

I developed this application as part of my Mobile App Development assignment. The main goal was to create an application that makes it easier to manage pantry ingredients and decide what meals to prepare.

One of the main challenges was working with SQLite to store and retrieve ingredient information. I also experienced emulator issues during development, which required troubleshooting and debugging to get the application running correctly.

### 🚀 Running the Project

1. Clone the repository.
2. Open Android Studio.
3. Select **Open** and choose the project folder.
4. Allow Gradle to sync.
5. Start an Android emulator or connect an Android device.
6. Click **Run** to launch the application.
